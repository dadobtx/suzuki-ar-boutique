1. DISEÑO (decidido con datos reales)
====================================================================
Mediciones de Dario con /#/diag-mano (laptop 1280×720, gestos + pose a la vez, umbrales 0.5):
  Gesto           1.5 m          2.0 m          2.5 m       (mano detectada / gesto correcto)
  Palma abierta   99 % / 99 %    91 % / 91 %    100 % / 100 %
  Índice arriba   97 % / 80 %    100 % / 100 %  100 % / 81 %
  Puño            100 % / 79 %   41 % / 36 %    65 % / 60 %    ← se pierde la mano: NO se usa
  Mano bajada     0 %            10 % sin gesto 0 %           ← bajar la mano apaga todo
  FPS 20–26, inferencia p95 ~22–35 ms por modelo.

Interacción:
  1. LEVANTAR LA PALMA ABIERTA activa el cursor. Moverla a izquierda/derecha recorre el perchero.
  2. QUEDARSE QUIETO 1.2 s sobre una prenda la toma (anillo que se llena, como el prototipo).
     Sobre la prenda que ya está puesta (gancho vacío) la devuelve. Sobre otra, la cambia.
     Es exactamente la acción que hoy hace el tap (handleTakeOrReturn).
  3. ATAJO: pasar de palma abierta a ÍNDICE ARRIBA sobre la prenda enfocada la toma al instante.
  4. BAJAR LA MANO pausa: el cursor desaparece y nada se dispara.
  NO hay puño.

4. ARQUITECTURA
====================================================================
4.1 src/lib/hand-cursor.ts  (PURO, sin React ni MediaPipe; toda la lógica testeable)
    Entrada por frame: { nowMs, hands: [{ wrist, palmCenter (landmark 9), gesture, score }],
                         user: { lockedWrists, sw, cx } (de pose.activeZone), itemCount,
                         busy, pausedUntilMs }
    Todo en coordenadas de lo VISIBLE (usar center-crop.ts igual que active-zone).
    a) Dueño de la mano: una mano es del usuario si su muñeca (landmark 0 de la mano) está a
       ≤ OWNER_DIST (0.08) de lockedWrists.left o .right. Las demás se ignoran. Si hay dos del
       usuario, usar la más alta (y menor).
    b) Activación: ventana de 250 ms; el cursor se activa si ≥ 60 % de los frames tienen la mano
       del usuario con Open_Palm o Pointing_Up (score ≥ 0.5). Se apaga si durante 400 ms no hay
       mano del usuario o el gesto es otro.
    c) Posición: x de palmCenter, ESPEJADA (el espejo se ve invertido), suavizada con One-Euro
       (reutilizar src/lib/one-euro-filter.ts).
    d) Mapeo a prenda RELATIVO AL CUERPO (la persona no camina, mueve el brazo):
         rango = [cx − REACH·sw, cx + REACH·sw], REACH = 1.6
         t = clamp((x − inicio) / ancho, 0, 0.999); índice = floor(t · itemCount)
       Histéresis: solo cambia de índice si t pasa el borde de la banda en más de 15 % del ancho
       de una banda.
    e) Permanencia: si el índice está quieto DWELL_MS (1200) con cursor activo y "armado" →
       evento { type: 'take', index }. Tras disparar queda DESARMADO hasta que el índice cambie o
       el cursor se apague (evita que se ponga y quite sola).
    f) Atajo: con cursor activo e índice estable ≥ 300 ms, si el gesto pasa de Open_Palm a
       Pointing_Up y se mantiene ≥ 70 % de 300 ms → { type: 'take', index } inmediato (mismo
       desarme).
    g) busy (vuelo en curso) o pausedUntilMs > now → no emite eventos y el progreso vuelve a 0.
    Salida: { state, cursor: { active, x, y, index, dwellProgress 0–1, gesture }, events[] }

7. TESTS NUEVOS
====================================================================
tests/unit/hand-cursor.test.ts:
- Mano lejos de lockedWrists → ignorada (no activa cursor).
- Mano del usuario con Open_Palm 60 % de 250 ms → activa; con 50 % → no.
- Sin mano 400 ms → cursor se apaga y el progreso vuelve a 0.
- Mapeo: x en cx − REACH·sw → índice 0; en cx + REACH·sw → último; en cx → el del medio.
- Espejado: mover la mano a la derecha de la imagen = cursor a la izquierda en pantalla.
- Histéresis: oscilar ±5 % de banda en el borde no cambia el índice.
- Permanencia: 1199 ms no dispara; 1200 ms dispara una vez; seguir quieto no vuelve a disparar;
  cambiar de índice y volver rearma.
- Atajo: Open_Palm → Pointing_Up sostenido 300 ms dispara; Pointing_Up desde el inicio (sin palma
  previa) no dispara el atajo (solo mueve el cursor).
- busy o pausa → no hay eventos.
- Con dos manos del usuario, se usa la más alta.
